# Web Application Projects

A collection of academic and personal projects showcasing my experience in web development, UX/UI design, and database-driven applications.

## Projects

## 1. Skill Swap Application — UX/UI Design

A peer-to-peer skill exchange application concept designed to help university students share skills, find peer tutors, schedule learning sessions, and build connections.

Focus: UX/UI design and user-centered design

Tools: Figma, UX research methods

Key Features: Skill search, matching, messaging, profiles, and feedback

## 2. Cédric Grolet Restaurant Website

A restaurant and pastry website inspired by Cédric Grolet, designed to showcase pastry products, store locations, and restaurant information.

Focus: Responsive web design and multimedia

Technologies: HTML5, CSS, JavaScript

Key Features: Menu, store locations, booking forms, and informational pages

## 3. ParkNbook — Parking Management System

A web-based parking management system developed as an academic project to support parking management and reservation functionality through a database-connected website.

Focus: Full-stack web development and database integration

Technologies: HTML, CSS, JavaScript, PHP, MySQL

Tools: WAMP Server, phpMyAdmin

Key Features: Parking reservations and database-driven management

## Purpose

This repository serves as a portfolio of projects demonstrating my skills in interface design, frontend development, backend development, and database integration.

These projects were created for learning and academic purposes. Refer to each project's folder for its source code, documentation, setup instructions, and additional resources where available.
