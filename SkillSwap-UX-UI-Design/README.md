## Skill Swap Application — UX/UI Design
A peer-to-peer skill exchange application designed to help university students learn from one another, share their expertise, and build meaningful connections.

### Project Overview
The Skill Swap Application is a user experience design project.

The application aims to create a collaborative student community where users can find peer tutors, exchange skills, schedule learning sessions, and provide feedback. It focuses on making peer learning more accessible, organized, and convenient for students with different needs and abilities.

### Key Features
Home Page: Introduces the application and helps users get started.

Login Page: Provides access to the application.

Search Page: Allows students to explore available skills and tutors.

Matching Page: Helps users discover suitable learning or skill exchange opportunities.

Messaging Page: Supports communication between students.

Feedback Page: Allows users to share their experience after a session.

Profile Page: Presents user information, skills, and learning preferences.

### Design Process
The project follows a user-centered design approach:

Empathize: Develop user personas, user stories, and a user journey map to understand students' needs and challenges.

Define: Identify the problems faced by learners, peer tutors, and students with accessibility needs.

Ideate: Conduct a competitive audit to explore existing skill exchange platforms and identify opportunities for improvement.

Prototype: Develop a low-fidelity user flow and a high-fidelity user interface in Figma.

### Tools Used
Figma: User interface design and prototyping.

UX Research Methods: Personas, user stories, user journey mapping, and competitive analysis.
