# Cédric Grolet Restaurant Website

### Project Overview
The Cédric Grolet website is a restaurant and pastry website inspired by the renowned pastry chef Cédric Grolet. The website allows visitors to explore the menu, discover store locations, learn about the brand, and place orders or make table reservations.

The website includes separate pages for different locations, such as Paris, London, and Singapore, providing visitors with an organized and user-friendly browsing experience.

### Purpose of the Website
The main purpose of the website is to present the restaurant and pastry brand online and provide customers with convenient access to its services.

The website aims to:
- Introduce the Cédric Grolet brand.
- Display the available menu and pastry products.
- Provide information about stores in different cities.
- Allow customers to submit order or reservation forms.
- Share information about the chef and the brand.
- Improve the customer experience through an attractive and responsive design.

### Technologies Used

### HTML5
HTML5 will be used to create the structure of the website and organize its content using semantic elements such as `header`, `nav`, `main`, `section`, `article`, `figure`, and `footer`.

### CSS
CSS will be used to style the website, including its layout, typography, colors, images, and responsive design. The project will demonstrate:
- External CSS through a stylesheet.
- Internal CSS through a `<style>` element.
- Inline CSS through the `style` attribute.

### JavaScript
JavaScript will be used to handle form inputs, validate customer information, and display messages based on user input or `if` conditions.

### Multimedia
The website will include at least four images of pastries, desserts, stores, or restaurant interiors. Video or audio will also be incorporated to improve the multimedia experience.

### Other HTML Features
The project will include:
- Hyperlinks connecting all webpages.
- A nested list for menu categories.
- An embedded iframe, such as a store map.
- A booking or ordering form.
- A table using `rowspan` or `colspan`.
- Responsive images and text.
- HTML5 semantic elements.

### Design and Navigation
The website design follows the supplied wireframe, with the home page serving as the main navigation hub.

The home page will contain links to:
- Choose Store
- Menu
- Book Table
- Other Pages

The Choose Store section will provide links to the Paris, London, and Singapore pages. The Other Pages section will link to the About Us page.

The visual design will focus on elegant typography, high-quality pastry photography, a clean layout, and a color scheme inspired by a luxury pastry brand.

### How to Run the Website
1. Download or copy the complete project folder.
2. Ensure all HTML, CSS, JavaScript, image, and media files are in their correct folders.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation links.
5. Test the forms, multimedia content, iframe, and responsive layout.
6. Check that all pages link back to the home page.
